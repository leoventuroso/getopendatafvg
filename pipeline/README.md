# Pipeline dati GIS

Questa cartella contiene gli script Python per produrre asset statici Jamstack:

- generazione layer `.pmtiles` con Tippecanoe;
- preparazione del file `community_data.duckdb`;
- future elaborazioni LTS, NDVI Sentinel-2 e QA dati territoriali.
- estrazione presidi/rescue da OSM con fallback a placeholder locali.

Gli script in Fase 0 sono volutamente placeholder strutturali.
